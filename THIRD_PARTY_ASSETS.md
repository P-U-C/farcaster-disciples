# Third-party assets

## The Disciples seal

`public/assets/disciples-mark.svg` is an original P-U-C cohort seal. Its protocol arch
references Farcaster's CC0 visual language, while its forked signal references the Network
State pledge. It does not reproduce either source mark.

The source reference files remain in `public/assets/farcaster.svg` and
`public/assets/network-state.svg`. The Farcaster reference comes from
[vrypan/farcaster-brand](https://github.com/vrypan/farcaster-brand) under CC0 1.0. The
Network State reference was supplied by [ns.com](https://ns.com/about/) under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
