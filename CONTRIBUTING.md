# Contributing

Data corrections are welcome when they include public proof.

1. Open an issue with the OG token number, FID, and links to the relevant chain records.
2. Explain whether the identity link is a custody address or a Farcaster verification.
3. Do not submit private wallet evidence, recovery phrases, API keys, or screenshots containing secrets.

For code changes:

```bash
npm ci
npm run verify
```

Keep methodology changes separate from visual changes so both can be reviewed precisely.
